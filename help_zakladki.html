🚀 TOTAL RESTART — Step by StepNAJWAŻNIEJSZE

Krok 1 — Przygotuj pliki XLSX

Per konto pobierz z panelu Allegro 3 raporty (okres: ostatnie 30 dni):
RaportSkąd pobraćNazwa zakładki w XLSX
Raport 1: AdsPanel Allegro → Reklama → Statystyki → Eksportuj"Statystyki*"
Raport 2: OdwiedzinyPanel Allegro → Sprzedaż → Odwiedziny wg ofert → Eksportuj"Odwiedziny wg ofert"
Raport 3: SprzedażPanel Allegro → Sprzedaż → Wg ofert → Eksportuj"Wg ofert"

Krok 2 — Otwórz Screener w MPlace Hub

Topbar → klik Screener (fioletowy button po prawej)

Krok 3 — Wgraj 3 pliki

Przeciągnij 3 pliki XLSX na pole uploadu w Screenerze. System automatycznie rozpozna typ każdego pliku (Ads / Odwiedziny / Sprzedaż) i konto. Sprawdź czy badge pokazuje 3 / 3 plików.

Krok 4 — Wpisz prompt

TOTAL RESTART — [nazwa konta]. [hero konta] = hero, [specjalizacja] = focus.

Przykłady:

KontoPrompt
MobelKapTOTAL RESTART — MobelKap. Półki wysuwane = hero, KARO 92 = specjalizacja MK, KARO 65 = MnC nie wrzucaj.
Perfekt CięcieTOTAL RESTART — Perfekt Cięcie. KARO 92 Lancelot = hero, donice Craft/Lancelot = specjalizacja PC, KARO 65 = MnC nie wrzucaj, TOP92 zostaw jeśli ROAS > 8.
Meble na CzasieTOTAL RESTART — Meble na Czasie. TOP92 Wotan = hero, KARO 65 Wotan = specjalizacja MnC, stoliki podnoszone = premium +2.5%.
Semmi (konkurencyjny)TOTAL RESTART — Semmi. Znajdź niszę rozmiarową gdzie Semmi może wygrać vs Luxsen, Materazzi, MtzzEU.
(wgraj 12 plików — 3 per konto × 4 konta)

Krok 5 — Czekaj na raport (~30-60 sek)

Agent zwraca JSON z danymi → JS renderuje raport z poprawnymi nazwami:
/001/D/ NAZWA KAMPANII i [KS][001][WW][RW] NAZWA_GRUPY

Walidator automatycznie:
✓ Usuwa oferty z ROAS < 3 (toksyczne)
✓ Usuwa duplikaty cross-grupa (kanibalizacja CPC)
✓ Usuwa KARO 65 z MK (specjalizacja MnC)
✓ Filtruje fake IDs (nie 11-cyfrowe)
✓ Auto-generuje wykluczenia Bestseller Automat
✓ Banner z listą naprawionych problemów

Krok 6 — Sprawdź raport

Co sprawdzić:
✓ Czy IDs są prawdziwe 11-cyfrowe (nie "sprawdź w panelu" na kluczowych)
✓ Czy hero konta ma najwyższy CPC i budżet
✓ Czy budżet łączny mieści się w celu Ads%
✓ Czy sekcja NIE PROMOWAĆ zawiera martwe punkty i specjalizacje innych kont
✓ Czy wykluczenia BA = wszystkie IDs z kampanii CORE

Krok 7 — Pobierz i wdrażaj

Klik HTML pod raportem → pobrany plik .html
Otwórz w przeglądarce obok panelu Allegro Ads → kopiuj nazwy kampanii, grupy, IDs

Kolejność w panelu Allegro:
1. Zamknij stare kampanie (lista w UWAGI KOŃCOWE)
2. Utwórz nowe kampanie wg planu (001, 002, 003...)
3. W każdej kampanii utwórz grupy, wklej IDs, ustaw CPC i budżet
4. Wgraj wykluczenia do Bestseller Automat
5. Aktywuj wyróżnienia FLAT/ELASTIC
6. Dynamic CPC ON → 7 dni ciszy → checkpoint 19.04
NIGDY nie oceniaj wyników Dynamic CPC przed upływem 7 dni. Algorytm się uczy. Spadek kliknięć w dniach 1-3 jest normalny. Pierwsza ocena: niedziela po 7 dniach.

▶ PLAY (Cockpit)CODZIENNIE

Co to jest

Codzienny cockpit operacyjny. 3-krokowy workflow: Data → Upload XLSX → 23 zadań. Agent AI generuje listę zadań na dziś na podstawie wgranych raportów (Ads + Sprzedaż + Konwersja per konto).

Kiedy używać

Rano, codziennie. Wgrywasz raporty z poprzedniego dnia, Agent generuje 23 zadań podzielonych na PILNE / WAŻNE / INFO. Checkboxy, progress bar, streak, timer, Did You Know.

Przykład użycia

CASE: Poniedziałek rano, 8:00
1. Klik ▶ → wybierz datę (wczoraj)
2. Wgraj 9 plików (3 typy × 3 konta MEBLE)
3. Agent generuje 23 kart z zadaniami
4. Odhaaczasz checkboxy w trakcie pracy w panelu Allegro
5. Progress bar pokazuje postęp, streak motywuje

Czego NIE robi

Nie analizuje głęboko — daje szybki przegląd dnia. Do głębokiej analizy → Analiza lub Screener.

📊 DashboardCODZIENNIE

Co to jest

Główny panel z liczbami. Sprzedaż, koszty Ads, ROAS, marża, wyróżnienia — per konto i per grupa. Wpisujesz dane ręcznie (brutto, dzień N = dane za dzień N-1). EOM projection dla bieżącego miesiąca.

Kiedy używać

Codziennie po wpisaniu danych. Sprawdź: czy marża rośnie, czy Ads% w celu, czy ROAS > BE. Porównanie m/m automatyczne.

🤖 AgentNA ŻĄDANIE

Co to jest

Chat z AI bez plików. Zadajesz pytania o strategię, Allegro Ads, optymalizację. Agent zna kontekst Twojego portfela (9 kont, 3 grupy, marże, ROAS).

Kiedy używać

Gdy potrzebujesz porady strategicznej — "Czy powinienem podnieść CPC na KARO 92?", "Jak przygotować się do Dnia Matki?", "Co zrobić z marżą 4.3% na PC?"

Czego NIE robi

Nie widzi plików XLSX. Jeśli chcesz analizę danych → Analiza lub Screener.

🔬 AnalizaCO TYDZIEŃ

Co to jest

Głęboka analiza ofert per konto. Wgrywasz 3 pliki XLSX (Ads + Sprzedaż + Odwiedziny) + opcjonalnie Ads 30d. Agent analizuje ROAS per aukcja, konwersję, martwe punkty i generuje raport 8-sekcyjny (Diagnoza → Wyłącz → Ostrzeżenie → Optymalizuj → Skaluj → Kanibalizacja → CTR vs Konwersja → Placement).

Kiedy używać

Co niedzielę — ocena tygodnia. Wgrywasz raporty 7d lub 14d i sprawdzasz co działa, co wyłączyć, co skalować.

Tryb TOTAL RESTART

FLOW: Total Restart kampanii (czysta karta)
1. Wybierz konto, wgraj 3 pliki
2. W uwagach wpisz: "TOTAL RESTART"
3. Agent zwraca JSON z kampaniami, grupami, IDs, CPC, budżetami
4. JS renderuje raport z poprawnymi nazwami: /NNN/D/ i [KS][NNN][WW][RW]
5. Walidator automatycznie: usuwa ROAS < 3, duplikaty, fake IDs, KARO 65 z MK
6. Gotowy raport z buttonami Kopiuj / HTML / Drukuj
CASE: Restart PC (11.04.2026)
Wgraliśmy 3 pliki PC → wpisali "TOTAL RESTART — Perfekt Cięcie" →
Agent wygenerował 9 kampanii z IDs → walidator usunął 17967722216 (ROAS 2.12×) →
Raport gotowy: /001/D/ STOLIK KAWOWY — KARO 92 HERO z [PC][001][WW][RW] KARO92_LANCELOT

Tryb diagnostyczny (domyślny)

Bez "TOTAL RESTART" w uwagach → Agent generuje raport diagnostyczny: co wyłączyć, co skalować, co zoptymalizować. Nie restartuje kampanii, analizuje istniejące.

⭐ WyróżnieniaCO TYDZIEŃ

Co to jest

Manager wyróżnień Allegro per konto. Dodajesz IDs aukcji które mają aktywne wyróżnienia. Agent w Analizie i Screenerze widzi te wyróżnienia i uwzględnia je w rekomendacjach.

Kiedy używać

Po każdej zmianie wyróżnień w panelu Allegro. Aktualizuj listę żeby Agent wiedział co jest promowane.

Dwa typy

TypKosztKiedyDla kogo
FLAT19.90 zł / 10 dniStałe, odnawialneHero z ROAS > 9×, min 8 trans
ELASTIC2.90 zł / dzieńNdz + Pon + Wt (peak)Dobre oferty wrażliwe na dzień tygodnia
Wyróżnienie ≠ Ads. Wyróżnienie = organika (pozycja w listingu). Ads = płatne kliknięcia. Nie wyłączaj wyróżnienia bo ROAS Ads niski — to dwa osobne kanały.

📋 StrategiaCO MIESIĄC

Co to jest

Strategia portfelowa grupy kont. Definiuje role kont (SCALE / NICHE / PREMIUM), podziały linii produktowych, cele Ads% i wyróżnień per konto.

Kiedy używać

Raz na miesiąc lub przy zmianie strategii. Przegląd ról, rewizja podziału linii, aktualizacja celów.

🎯 Centrum AdsCO TYDZIEŃ

Co to jest

Panel Ads z dwoma narzędziami: AI Architect (plan reorganizacji 3 kont) i Ads Tracker (checkpointy 7/14/30d po restarcie).

AI Architect

Wgraj 3 raporty Ads (MK + PC + MnC) → Agent buduje globalną mapę kampanii, wykrywa kanibalizację cross-account i wewnątrz kont, proponuje reorganizację wg ról portfelowych.
CASE: Reorganizacja 33 kampanii (10.04.2026)
Wgraliśmy 3 raporty Ads → AI Architect wykrył 47 aukcji cross-account i 23 duplikaty →
Wygenerował tabelę z akcjami per kampania: ZACHOWAJ / OCZYŚĆ / ZAMKNIJ / PRZENIEŚ →
Sekcja PODSUMOWANIE GRUP z IDs do wklejenia w panelu Allegro

Ads Tracker

Po restarcie kampanii — wgrywasz raporty co 7 dni i porównujesz ROAS z benchmarkiem. Alerty jeśli ROAS spada poniżej BE.

💬 ScreenerNA ŻĄDANIE

Co to jest

Najbardziej elastyczne narzędzie. Chat z Agentem + upload plików XLSX + wklejanie screenshotów (Ctrl+V). Multi-turn: pełna historia konwersacji. Agent widzi pliki, obrazki i odpowiada na pytania.

Kiedy używać

Gdy potrzebujesz iteracji. Analiza daje jeden raport. Screener pozwala dopytywać, korygować, drążyć. "Pokaż mi AOV per konto", "Porównaj TOP92 na MK vs MnC", "Dlaczego ta oferta nie konwertuje?"
