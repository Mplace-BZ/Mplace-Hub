## Co potrzeba żeby to zadziałało

Allegro REST API wspiera dwa flow:

| Flow | Czy pasuje | Trudność |
|------|-----------|---------|
| **Authorization Code** | Tak — mamy GitHub Pages + redirect | Srednia — trzeba strony `/callback` |
| **Device Authorization** | Tak — łatwiejszy, bez callback page | Prosta — tylko polling |

**Device Authorization** byłby prostszy — użytkownik otwiera link, zatwierdza w przeglądarce, token wraca przez polling. Żadnej strony callback.

| Ryzyko | Poziom | Dlaczego |

## 1. PARSER XLSX vs. REST API (allegro-parser.mjs)

**Ścieżka**: `/Users/chrismac/MPlace-Agent/agents/ads-specialist/allegro-parser.mjs`

```javascript

  gwiazdy: [],          // ROAS &gt;= 7, min 3 szt lub koszt &gt;= 50 zł

```

#### Type: `'sprzedaz'` (Odwiedziny wg ofert)
- **Szukane kolumny:** Nazwa oferty, ID oferty, Liczba wizyt, Transakcje, Konwersja, Dodania do koszyka, Dodane do ulubionych, Polubienia
- **Zwraca:**

#### Type: `'konwersja'` (Sprzedaż wg ofert — INNY format)
- **Szukane kolumny:** Nazwa oferty, Wartość sprzedaży
- **Zwraca:**
```javascript
{
  type: 'konwersja',
  oferty: [],
  totWartosc
}
```
